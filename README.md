# Info Décisionnelle — Offline Website

This website is fully offline-ready.

## Files

- `index.html` — main page
- `styles.css` — page styles
- `script.js` — interactive behavior

## Usage

Open `index.html` directly in your browser.

If you prefer a local server, run one from the folder:

```bash
cd /home/ilias_m/RevisionInfoDecisionnelleWebsite
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

- The site no longer loads any external fonts or resources.
- It works without a network connection.
